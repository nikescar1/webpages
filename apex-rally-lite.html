Apex Rally Lite is an original, completely self-contained game. All code, the WebGL renderer, vehicle physics, procedural audio synthesis and track generation were written from scratch for this build. No external engines, libraries, textures, fonts or audio samples are used — everything is generated at runtime in plain JavaScript and WebGL.

Vehicle physics (raycast-style suspension feel, tire slip/grip, arcade collision response) is conceptually inspired by the rigid-body/collision approach of isaac-mason/crashcat (MIT License). This is a hand-written, original arcade physics implementation tuned for feel — not a port of that code.

Built as a single self-contained HTML file. Thanks for playing!
